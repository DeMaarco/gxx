# GXX visual assets

The SVG compositions in this directory are original procedural artwork authored for the gxx website. They use the same core vocabulary as the WebGL scenes: deep graphite, cyan/violet signal lines, orbital geometry, workspace boundaries, and context nodes.

They are not stock images and do not contain third-party image assets. Each composition has a specific role:

- `hero/hero-core.svg` — core system / hero fallback
- `workspace/workspace-atlas.svg` — repository context space
- `security/security-boundary.svg` — sensitive path boundary
- `agent/agent-context.svg` — prompt-to-action flow
- `open-source/open-source-network.svg` — repository network
- `cta/cta-core.svg` — minimal closing core
